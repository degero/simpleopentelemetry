# SimpleOpenTelemetry configuration snippets

These files allow guidance for any components that use options. Options provided are the full set supported (not all mandatory) with values set as either defaults from the component code or an example value.

Some components may allow either a top-level 'all signal' options configuration or in the specific signal configuration area. A signal area configuration overrides the top-level configuration.

For full details for all non-configurable components or on any of these components options refer to the [README.md Configuration Details](../README.md#configuration-details)
