# Google Hosted SimpleOpentelemetry app settings

Included in these files are the minimum recommended resource attributes and tracing set under `SimpleOpenTelemetry:Trace:Sources` for an dotnet app with the root namespace `soteltestgcp`. Adjust these as suited to your app name / namespace / version / deployment env.

See information in [../README.md](../README.md) and [otelj-collector-config/README.md](../otel-collector-config/README.md) for google environment setup and permisions as well as specific constraints in GCP that affect app telemetry collection (eg. Cloud Run's automatic tracing / sampling)

**IMPORTANT**: ⚠️ **It is recommended you install [these versions tested against SimpleOpenTelemetry](../../../../../docs/otel-component-versions.md) of packages referenced below.** ⚠️

## appsettings.OtelCollector.json

This is designed for use running an aspnetcore app containerised with a otel collector sidecar. While there is a Google resource detector, this is included on the collector rather than here. It requires the following nuget packages:

```
SimpleOpenTelemetry
OpenTelemetry.Instrumentation.AspNetCore --version x.x.x
OpenTelemetry.Instrumentation.Http --version x.x.x
```

## appsettings.DirectExport.json

This is designed for use running an aspnetcore app with no collector and exports directly to Google's OTLP endpoints.
It requires the following nuget packages:

```powershell
SimpleOpenTelemetry
Google.Apis.Auth
OpenTelemetry.Instrumentation.AspNetCore --version x.x.x
OpenTelemetry.Instrumentation.Http --version x.x.x
OpenTelemetry.Resources.Gcp --version x.x.x
```

It also requires custom code which you can see in the example [app/Program.cs](../app/Program.cs). It configures telemetry key adjustments to work correctly with Google Observability as done by the OpenTelemetry collector configs in the [otel-collector-config](../otel-collector-config/) folder.

Key adjustments are in the files:

- [GcpCloudRunTraceIgnore.cs](../app/GcpCloudRunTraceIgnore.cs) - Ignore parent traces cloud run injects
- [GcpLogSeverityTextProcessor.cs](../app/GcpLogSeverityTextProcessor.cs.cs.cs) - Fix log levels for google expected values
- [GcpLogNameProcessor.cs](../app/GcpLogNameProcessor.cs.cs) - Logs can be set to a different name than the default 'otlp'
- [GoogleCloudBearerTokenProvider](../app/GoogleCloudBearerTokenProvider.cs) - Handle Auth token retrieval / refresh to export to google otlp endpoints
- [HealthCheckFilterSampler.cs](../HealthCheckFilterSampler.cs) - Filters out healthcheck traces generated by aspnetcore instrumentation

The `OpenTelemetry.Resources.Gcp` detector used does not cover all the attributes that the OpenTelemetry collector gcp processor does. A demonstration in the sample app [GcpResourceDetector.cs](../app/GcpResourceDetector.cs) will insert a missing attribute `faas.instance`. Check here for a newer version if they have covered this:

[Github - GCP resource detector](https://github.com/open-telemetry/opentelemetry-dotnet-contrib/tree/main/src/OpenTelemetry.Resources.Gcp)

[Github - Otel Collector GCP processor](https://github.com/open-telemetry/OpenTelemetry-collector-contrib/blob/main/processor/resourcedetectionprocessor/internal/gcp/documentation.md)
